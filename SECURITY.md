# Security policy

Please do not open a public issue for a suspected security vulnerability. Instead, use the repository's GitHub **Security** tab to submit a private vulnerability report. Include affected versions, reproduction steps, and the potential impact when possible.

Only the latest release receives security fixes while nagame is pre-1.0.
